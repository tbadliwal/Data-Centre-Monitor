About this monitor

What is live, what is curated, and what the model interprets

The monitor deliberately separates source discovery from verified legal conclusions. That is the only credible way to keep it current without turning a headline into “law.”

Curated baseline

Human-reviewed layer last revised Aug. 31, 2026. It contains state risk classification, screening bucket, audited regulatory summary, verified event history, governor roster, and verified political-stance evidence. It does not auto-change from news.

Live discovery

GitHub Actions refreshes the public-news discovery dataset on a schedule. The updater enforces a strict rolling 15-day cutoff, removes stale fallback results, deduplicates stories and sorts them newest-first.

Automated interpretation

The updater derives a 15-day friction signal and a separate governor signal from current headlines/snippets. These are screening indicators only. They are always labeled automated and never overwrite verified risk or stance.

Why the baseline date stays

The date is intentionally honest. Making “Aug. 31” automatically turn into today without re-verifying laws would create false freshness. The website instead overlays current discovery and signals on top of the last curated baseline.

Source hierarchy

  • Primary source: government/regulator/utility/court where detected.
  • Credible reporting: Reuters/AP.
  • Discovery: other public reporting that requires verification.

Refresh cadence

The live layer can run every six hours or weekly; six-hour refresh is more useful and inexpensive. The browser also reloads the latest same-origin JSON periodically while the page is open.
