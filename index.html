About this monitor

What is live, what is curated, and what you can trust

This page intentionally separates speed from verification. The discovery layer can update while the file is open; the verified regulatory record only changes when the underlying database is rebuilt after source confirmation.

What the website does

  • Tracks all 50 states plus federal developments affecting data-center construction and operation.
  • Flags power/interconnection, utility cost allocation, permitting, zoning, water, incentives, litigation, project withdrawal and organized opposition.
  • Maintains a Political Desk for governors and other officials where an explicit data-center position has been documented.
  • Pulls a filtered 15-day live-news discovery feed each time the site opens and each time a state is clicked.

What updates automatically

  • Live discovery: queries public-news discovery’s DOC 2.0 public-news index for U.S.-source, English-language data-center policy coverage over the last 15 days.
  • Live pulse: recomputes article themes and likely state activity on every successful refresh.
  • Local cache: the last successful live results are saved in your browser, so a temporary API outage does not leave a blank page.
The live layer is discovery only. It does not automatically rewrite a state’s verified risk rating or mark a bill as enacted.

What is static in this portable file

  • Verified regulatory baseline: Aug. 31, 2026.
  • Governor roster: National Governors Association, checked Aug. 31, 2026.
  • Risk ratings, political stance evidence and verified event summaries remain fixed until the HTML/database is rebuilt.

A downloaded HTML file cannot update itself while your computer is closed. A permanent always-current URL requires hosting plus a scheduled backend/build process.

Primary source hierarchy

Tier A · legislatures, governors, PUC/PSC regulators, environmental agencies, municipalities/counties, utilities and court records.
Tier B · Reuters, AP and credible local reporting used for discovery/context when primary confirmation is unavailable.
Live discovery · filtered public-news leads. Never sufficient by itself to change legal status.

Core sources

  • National Governors Association — current governors ↗
  • public-news discovery DOC 2.0 — public-news discovery ↗
  • State legislature, governor, regulator, utility and local-government pages linked within each verified event.

Interpretation

  • Critical: active freeze/hard-stop or unusually severe development interruption.
  • High: binding or highly probable constraints with material project impact.
  • Elevated: meaningful regulatory/political risk is advancing.
  • Watch: no material restrictive action verified yet; not the same as “safe.”
